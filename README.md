# 🎮 Run 1 3DS — Beta 0.9

The first public beta of **Run 1 for Nintendo 3DS!**

This is an unofficial fan-made homebrew port of the classic 2008 Flash game *Run*, originally developed by **Player_03**.

The goal of this project is to bring the original Run experience to Nintendo 3DS while preserving its classic gameplay, graphics, and atmosphere.

### ✨ Features
- 👽 Original gray alien sprites and animations
- 🗺️ 50 original Adventure Mode level layouts
- 🌌 Classic space background and tunnel graphics
- 🎵 Original soundtrack with Music ON/OFF settings
- 🎮 Nintendo 3DS button and touchscreen controls
- 💾 Save support for Adventure Mode progress
- 🏠 Classic-style title screen and menus
- 📦 Native CIA and 3DSX support

### 📥 Installation

**CIA Version**
1. Download `Run1_2008_3DS.cia`.
2. Install it using a compatible CIA installer.
3. Launch Run 1 from your HOME Menu.

**3DSX Version**
1. Download `Run1_2008_3DS.3dsx`.
2. Place it in the `/3ds/` folder on your SD card.
3. Launch it through the Homebrew Launcher.

### ⚠️ Known Limitations
- Infinite Mode and Edit Mode are not yet implemented.
- Some movement physics and level visuals differ from the original Flash game.
- Minor graphical glitches and performance issues may occur.
