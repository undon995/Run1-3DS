Run 1 3DS — Beta 0.9
An unofficial Nintendo 3DS homebrew port of Run, the classic Flash game created by Player_03. This is a work-in-progress fan project bringing the recognizable gray alien and tunnel-running gameplay to Nintendo 3DS.
> **Beta release:** This is not a complete or exact recreation of the original Flash game. Some mechanics, menus, visuals, and modes are still being developed.

Features
Native Nintendo 3DS homebrew application
Original gray alien sprite artwork extracted from the supplied Flash game
50 Adventure level layouts sourced from the Flash game and adapted to the 3DS engine
Starfield, original-style menus, and level selection
Music playback support and an On/Off setting
Adventure progress saving
Physical button and touchscreen controls
Builds for both CIA and 3DSX formats
Installation
CIA — HOME Menu
Obtain a release build that you are authorized to use.
Install the `.cia` using a compatible installer on a homebrew-enabled Nintendo 3DS, or import it into a compatible emulator.
Launch Run 1 3DS from the HOME Menu.
3DSX — Homebrew Launcher
Copy `Run1_2008_3DS.3dsx` to the `/3ds/` folder on your SD card.
Open the Homebrew Launcher.
Select Run 1 3DS.

Known limitations
The tunnel camera, platform rendering, collision, and movement physics may differ from the original Flash version.
Infinite Mode and Edit Mode are shown in the menu but are not yet ported.
The original Flash game's full functionality and timing are not guaranteed.
Performance and audio behavior may vary between hardware and emulators.
Please report reproducible problems with the level number, what happened, and whether you tested on hardware or Azahar.
